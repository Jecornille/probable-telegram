# Arbre généalogique

Application web pour visualiser et construire un arbre généalogique interactif.

## Fonctionnalités

- Affichage de l'arbre sous forme de diagramme (générations, couples, liens parent-enfant)
- Ajout, modification et suppression de personnes (nom, sexe, dates, lieu de naissance, notes)
- Liens de parenté (jusqu'à 2 parents) et de couple (conjoint·e·s)
- Zoom et déplacement (pan) dans le diagramme
- Recherche dans la liste des personnes
- Sauvegarde automatique dans le navigateur (localStorage)
- Export / import des données au format JSON

## Démarrage

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
```
